# 技术栈规划

## 1. 引擎与基础

| 类别 | 方案 |
| --- | --- |
| 引擎版本 | Unity 2022 LTS |
| 开发语言 | C# |
| 版本管理 | Git |
| IDE | Rider / Visual Studio 2022 |

## 2. 运行时技术栈

| 类别 | 方案 | 用途 |
| --- | --- | --- |
| 运行时 UI | UGUI | HUD、运行时面板、战场信息与交互界面 |
| 输入 | Input System | 鼠标、键盘、快捷键、可扩展输入映射 |
| 资源管理 | Addressables | 资源加载、内容组织、后续扩展 |
| 相机 | Cinemachine 3 | 镜头控制、观察模式、过场与聚焦 |
| 路径 | Splines | 路径、轨迹、巡逻线、投送线 |
| 渲染 | URP | 主渲染管线 |
| 材质与特效 | Shader Graph | 节点化材质与部分视觉效果 |

## 3. 代码逻辑技术栈

| 类别 | 方案 | 用途 |
| --- | --- | --- |
| 运行时状态 | Plain C# Classes | 承载运行时状态，不直接依赖场景对象 |
| 业务组织 | Service / System | 按系统域组织核心逻辑 |
| 协作方式 | Command / Query / Event | 系统间请求、查询与通知 |
| 异步流程 | async/await + UniTask | 初始化、加载、流程控制 |
| 依赖管理 | VContainer | 控制模块依赖关系与模块装配 |

## 4. 编辑器与内容生产工具链

| 类别 | 方案 | 用途 |
| --- | --- | --- |
| 编辑器 UI | UI Toolkit | 配置工具、调试窗口、编辑器辅助工具 |
| 配置载体 | ScriptableObject | 定义数据、配置数据 |
| Inspector 增强 | 原生 Inspector 扩展 / 可选 Odin Inspector | 提升配置与调试效率 |

## 5. 测试与质量保障

| 类别 | 方案 | 用途 |
| --- | --- | --- |
| 自动化测试 | Unity Test Framework | EditMode / PlayMode 测试 |
| 日志与调试 | Unity Console / 自定义调试输出 | 开发期问题定位 |
| 性能分析 | Unity Profiler | 性能热点分析与优化验证 |

## 6. 高级技术验证

| 类别 | 方案 | 用途 |
| --- | --- | --- |
| 高性能模拟 | Entities 1.4 + Burst + Jobs + Collections | 用于高频、大规模、批量更新模块 |
| AI 可视化 | Unity Behavior | 行为树、可视化 AI 编排 |

### 6.1 高性能栈适用模块

| 技术 | 建议使用范围 |
| --- | --- |
| Entities 1.4 | 大规模单位状态、批量模拟对象、数据导向运行时层 |
| Burst | 高频纯计算逻辑、批量结算、热点规则计算 |
| Jobs | 可并行拆分的批量处理任务 |
| Collections | 原生高性能容器与批量数据结构 |

| 建议接入模块 | 说明 |
| --- | --- |
| 单位与编队系统 | 大量单位状态更新与批量行为处理 |
| 资源与网络系统 | 批量供给结算、网络分配、影响传播 |
| 侦察与视野系统 | 批量视野扫描、区域判定 |
| 威胁与袭扰系统 | 威胁扩散、影响图、批量事件计算 |
| 战斗与伤害系统 | 批量目标筛选、命中与伤害结算 |

| 不建议优先接入模块 | 说明 |
| --- | --- |
| UGUI 运行时界面 | 以表现和交互为主，不适合作为高性能栈入口 |
| 局内流程系统 | 以流程编排为主，不是性能热点 |
| 局外薄层系统 | 数据量小、规则频率低 |

## 7. 当前技术取向

| 类型 | 结论 |
| --- | --- |
| 运行时优先 | 优先采用成熟稳定方案，保证项目可交付 |
| 技术亮点 | 在高频模拟层、编辑器工具链、AI 编排上引入高级技术 |
| 引入原则 | 先保证主线闭环，再逐步接入前沿技术 |

## 8. 可选技术项

| 技术 | 可能用途 | 可能接入模块 |
| --- | --- | --- |
| Odin Inspector | 提升配置录入、调试与 Inspector 表达效率 | 数据设计、配置工具、开发调试 |
| Unity Behavior | 可视化行为树与 AI 编排 | AI 对抗、威胁与袭扰、单位行为 |
| FMOD | 音频事件、混音、动态音频控制 | UI、战斗、告警、环境反馈 |
| Wwise | 更完整的音频中间件工作流 | UI、战斗、告警、环境反馈 |
| DOTween | UI 动画、提示动效、镜头过渡 | UGUI 运行时界面、过场表现 |
| TextMeshPro 扩展工具 | 富文本、数值弹字、动态文本表现 | UGUI、战场信息、告警界面 |
| Rewired 或同类输入增强方案 | 更复杂的输入兼容与重绑定 | 输入系统、指挥与命令系统 |
| GraphView / 自定义图编辑工具 | 可视化编辑链路、事件、行为图 | 编辑器工具、数据设计、AI 工具 |
| YAML / JSON 导入导出工具 | 表驱动导入、外部配置同步 | 数据设计、配置工具、局外内容 |
| CSV / Excel 导表工具 | 策划表转配置资产 | 建筑、单位、蓝图、事件配置 |
| 自定义 Profiling / Telemetry | 性能热点观测、运行时统计 | 资源与网络、单位、战斗、AI |
| 崩溃与日志收集方案 | 运行日志、错误追踪、构建验证 | 全局运行时、测试构建 |
